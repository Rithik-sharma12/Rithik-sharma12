# Profile README — setup and editing

## Install (5 minutes)

1. Copy everything except `SETUP.md` and `preview.png` into the root of the
   `Rithik-sharma12/Rithik-sharma12` repository:
   `README.md`, `assets/`, `.github/`, and optionally `build.py` + `fonts/`.
2. Commit and push to `main`.
3. Repository → **Actions** → **generate-snake** → **Run workflow**.
   The snake stays blank until this has run once; after that it refreshes daily.

`preview.png` shows what the finished profile looks like.

## Editing the artwork

The cards are SVG files generated by `build.py`. Edit the text there, never in
the SVGs directly, so the layout stays consistent.

```bash
pip install fonttools brotli
python build.py        # rewrites everything in assets/
```

Common edits:

- **New certification** — add a tuple to the `certs` list in `log()`.
  The card holds seven comfortably; past nine, raise `h` in `log()`.
- **New project** — copy one of the `small(...)` calls at the bottom, then add a
  matching `<a><img></a>` pair in `README.md`. Cards sit in pairs.
- **Job-search status** — the green chip in `hero()`. Change it when you accept
  an offer.

Design rules the generator follows, if you extend it:

- Green `#3DFF8F` is the only accent. Amber `#FFB84D` means *selected* and is
  used for nothing else.
- One typeface, JetBrains Mono, embedded in each file so it looks identical on
  every machine. Hierarchy comes from weight (400 vs 800), not extra fonts.
- No invented numbers — no skill percentages, no fake metrics.

## If the stats cards are blank

`github-readme-stats.vercel.app` is shared by a huge number of profiles and is
often rate-limited. Deploy your own free copy on Vercel (one click from that
project's GitHub page) and swap the hostname in the two stats `<img>` tags.

## Worth adding

- A TryHackMe or Hack The Box badge. For offensive-security hiring it is the
  most credible single signal a profile can carry.
- Descriptions for `Flag-Frenzy25`, `SODAK_SOLVE` and `Sodak-Tech` — they have
  none, so they were left off rather than guessed at.
